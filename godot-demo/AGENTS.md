# Nicole 的 Godot 工作偏好

- 可視元素與 UI 優先建立為存於 .tscn 的 Godot 原生節點，開啟場景即可預覽、選取、拖動、縮放和替換素材。
- 不把主要場景布局藏於 _draw()、執行時建立元件或硬編碼座標中。動態繪圖僅用於必要的短暫效果。
- 互動熱區、標籤與狀態提示隨其設備節點移動；玩法從場景節點讀取位置，不維護另一套固定座標。
- 程式不得在啟動時重設 Nicole 已在編輯器調整的布局。修改前先讀取實際 Godot 工程，保留她的調整。
- 占位素材與正式素材可替換，玩法邏輯與視覺分離。
- 每個頁面使用獨立 .tscn；重複元件及製作設備拆成可重用子場景。main.tscn 為入口及場景組合，不堆放所有頁面的內部節點。
