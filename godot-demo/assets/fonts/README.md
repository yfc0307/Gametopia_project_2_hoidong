# 字體來源與用途

- jf-openhuninn-2.1.ttf：justfont 官方粉圓2.1，用於共用 UI Theme。
  https://github.com/justfont/open-huninn-font
  https://raw.githubusercontent.com/justfont/open-huninn-font/master/font/jf-openhuninn-2.1.ttf
  授權：OFL-openhuninn.txt。
- Iansui-Regular.ttf：ButTaiwan 官方芫荽，用於遊戲內設備名稱與狀態標籤。
  https://github.com/ButTaiwan/iansui
  https://raw.githubusercontent.com/ButTaiwan/iansui/main/fonts/ttf/Iansui-Regular.ttf
  授權：OFL-Iansui.txt。

兩者原始字體檔未修改；授權文件保留在同一資料夾並應隨遊戲發行。無須安裝到作業系統，Godot 使用專案內的 FontFile。拖拽標籤從來源設備複製字體設定。
